## 🌱 About me

I work on **cyber-physical systems**: places where software meets the physical world.
That means sensors and IoT, the data they produce, the models that learn from it, and the
apps people use to act on it.

I like working across disciplines rather than staying in one lane, so my work moves between
embedded and connected devices, machine learning, backend services, desktop and web apps,
and the occasional game.
